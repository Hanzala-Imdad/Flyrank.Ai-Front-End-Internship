## General Conventions

* Keep assignment work organized inside the appropriate assignment folder.
* Keep changes focused on the current task.
* Do not modify unrelated files.
* Prefer clear, simple, and maintainable solutions.
* Do not add dependencies unless they are required.
* Review changes before committing.
* Use clear and consistent naming.
* Follow Conventional Commits for Git commit messages.

## Git Commit Format

Use:

`<type>: <description>`

Examples:

* `feat: add ...`
* `fix: resolve ...`
* `docs: update ...`
* `chore: configure ...`
* `refactor: improve ...`

## AI Assistant Rules

* Inspect the relevant files before making changes.
* Explain important changes when appropriate.
* Do not make unrelated modifications.
* Preserve existing project intent.
* Review the final changes after editing.
